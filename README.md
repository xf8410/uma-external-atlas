# 赛马娘外部开源项目图鉴

收录 **34 个不属于本项目组的社区开源仓库**，逐个用中文说明它们到底做什么。

在线浏览：<https://xf8410.github.io/uma-external-atlas/>

## 页面结构

单页应用（`index.html`），五个方向分区：

| 分类 | 仓库数 | 解决什么 |
|---|---|---|
| 🤖 自动育成与挂机 | 10 | 重复育成太累：自动选训练、排赛程、管体力、刷比赛 |
| 🌐 本地化与汉化 | 6 | 看不懂日文：改文本表、代码注入、译文分离管理 |
| 📦 数据提取与资源查看 | 7 | 想研究游戏数据：资源浏览、语音台词提取、数据库开放 |
| 🛠️ 辅助工具与启动器 | 6 | 帮你玩得更好：启动器、选项推荐、Mod 加载、浮层翻译 |
| 🧮 模拟器与计算器 | 5 | 只算账：训练概率、相性、数据库浏览、强度榜 |

每个仓库一个卡片，标注星标 / 语言 / 维护状态，功能逐条拆开，底部按钮直达 GitHub。底部附「全部仓库总表」（按星标降序）与「怎么挑」对照表。

## 收录标准

- 属于外部社区（xf8410 及项目组成员以外的个人或组织）
- GitHub 上公开可访问
- 与赛马娘相关且有一定可用性
